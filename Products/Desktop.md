# Allternit Desktop

## What it is

The primary user-facing product: an Electron desktop app that bundles the platform UI, platform server, `allternit-api`, `gizzi-code`, and SQLite. Uses a BYOC (Bring Your Own Compute) model — the desktop is the compute, with optional Cloudflare Tunnel for web access.

## Current phase

Active development.
